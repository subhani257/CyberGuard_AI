## Documentation Standard

Each entry in this folder adheres to standard production incident & architectural review guidelines:
1. **Executive Summary & Problem Statement:** High-level description of what occurred.
2. **Symptoms & Trigger Event:** Observable issues in UI or backend logs.
3. **Root Cause Analysis (RCA):** Deep technical explanation of why naive or legacy approaches failed.
4. **Failure Modes:** How the issue impacted downstream LLM reasoning, security simulations, or database integrity.
5. **Architectural Solution:** Dual-layer designs, schemas, fallback pipelines, and prompt contracts.
6. **Comparative Matrix (Before vs. After):** Clear evaluation of systemic improvements.
